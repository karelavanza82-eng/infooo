# Parallel style (Hoisly)

Settings -> Animation style -> **Parallel**. Each tap plays the Default Hoisly surface animation on its
own; taps are never ignored and there is no limit. Apps open only after 0.4 s without a tap, in the
order tapped (0.15 s apart), with a short fade-in. Needs "Animasi buka/tutup aplikasi" on.
Not compiled or run on a device by the author of this patch.
