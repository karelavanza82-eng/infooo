HOISLY - RETURN-TO-HOME FIX + RENAME

1. No more "refresh" when coming back to the home screen
   - Resume animation (home faded in from empty + zoomed) is OFF by default for everyone.
     Setting key changed to resume_animation_v2 so old saved "on" values are reset.
     It can still be turned on in Settings > Animations.
   - Icon bitmap cache is now shared by the whole process (IconLoader.SHARED_CACHE): when the
     home activity is created again, icons are drawn immediately instead of appearing one by one.
   - Blurred wallpaper / glass images are remembered per process (LauncherViewModel.lastWallpaper):
     a new ViewModel no longer starts with a grey dock and re-runs the heavy blur pass.
   - MainActivity configChanges extended (fontScale|colorMode|mcc|mnc|touchscreen) so such
     configuration changes do not recreate the home activity.

2. Name: "Dynamic Island" -> "Hoisly"
   - App name (all languages, including Indonesian which still said Dynamic Island), accessibility
     service label, quick-settings texts, settings pages, Keep-alive instructions, i18n JSON files.
   - Kept on purpose: credit to the original PC project "Dynamic Island for Windows" (github link).
